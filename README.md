# favicon-audit
`python3 favicon_audit.py https://your-site.com/` lists every icon your homepage declares, checks each one loads, and flags missing `apple-touch-icon`, manifest, or `/favicon.ico`. stdlib only.

*Disclosure: I build [IconPack](https://iconpack.adjudi.com/?utm_source=github&utm_medium=readme&utm_campaign=iconpack-intent-w2&utm_content=favicon-audit) ($19), which generates the full set from your site. This script is free (MIT).*
